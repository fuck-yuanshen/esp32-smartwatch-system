# 基于 ESP32 的智能手表系统

这是一个由 ESP32 手表固件和 Android 配套应用组成的智能手表系统，包含显示交互、传感器、电子书、闹钟、Wi-Fi/BLE 管理等功能。

## 目录

- `firmware/`：ESP32 手表固件及随附库
- `android/`：Android 配套应用

## 开发环境

- ESP32 Arduino/PlatformIO 工具链
- Android Studio、Android Gradle Plugin
- 根据实际硬件准备显示屏、传感器和音频模块

## 使用说明

请先阅读两个子目录中的源码注释和配置文件，再根据实际硬件修改引脚、无线网络和服务参数。无线网络密码、签名文件和本机 SDK 配置不应提交到仓库。

## 第三方声明

固件中使用的第三方库及驱动应遵循各自的开源许可证，具体以对应目录中的声明为准。
